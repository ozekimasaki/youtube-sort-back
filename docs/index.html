プライバシーポリシー

対象: Chrome 拡張機能「Bring Back YouTube Search Sort (Upload Date / Views)」

最終更新日: 2026-01-30

本拡張機能は、YouTube 検索結果ページに「最新順」「視聴回数順」の並び替えボタンを表示し、 クリック時に URL のクエリパラメータ（sp）を変更してページ遷移することで並び替えを行います。

1. 収集する情報

本拡張機能は、個人情報を含むユーザー情報を収集しません。

2. 情報の利用目的

本拡張機能は情報を収集しないため、利用目的はありません。

3. 第三者提供

本拡張機能は情報を収集しないため、第三者提供は行いません。

4. 外部送信（ネットワーク通信）

本拡張機能は、拡張機能としての外部サーバーへの通信を行いません。 ただし、ユーザーが YouTube を閲覧することにより、YouTube（Google）が提供する通常の通信は発生します。

5. ローカル保存（端末内への保存）

本拡張機能は、設定や履歴等の情報を端末内に保存しません（chrome.storage 等は使用しません）。

6. Cookie / トラッキング

本拡張機能は Cookie を設定せず、トラッキング目的の識別子等も利用しません。

7. 変更

本ページの内容は、機能追加や法令等の変更に応じて改定される場合があります。

8. お問い合わせ

お問い合わせは、公開している GitHub リポジトリの Issues からお願いします。

Privacy Policy (English)

Applies to: "Bring Back YouTube Search Sort (Upload Date / Views)" Chrome Extension

Last updated: 2026-01-30

This extension displays "Upload Date" / "Views" sort buttons on YouTube search result pages and performs sorting by navigating to a URL with a modified query parameter (sp).

1. Information We Collect

We do not collect personal information or any user data.

2. How We Use Information

Since we do not collect information, we do not use it for any purpose.

3. Sharing with Third Parties

We do not share information with third parties because we do not collect it.

4. Data Transfers / Network Requests

The extension does not send data to external servers. Normal network traffic to YouTube (Google) occurs when you browse YouTube.

5. Local Storage

The extension does not store settings or history on your device (it does not use chrome.storage).

6. Cookies / Tracking

The extension does not set cookies and does not use tracking identifiers.

7. Changes

We may update this policy as the extension changes or to comply with laws and regulations.

8. Contact

Please contact us via GitHub Issues in the public repository.
